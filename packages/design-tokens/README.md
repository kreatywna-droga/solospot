# @web-factor/design-tokens

Central source of design tokens for WEB FACTOR ecosystem:
- Colors (Primary, Secondary, Neutral, Success, Warning, Error, Info with 50-900 scales)
- Spacing (4px base unit scale)
- Typography (Families, Sizes, Weights, Line Heights, Letter Spacings)
- Layout (Breakpoints, Containers, Z-Index, Radius, Shadows)
- Theme Definition API
