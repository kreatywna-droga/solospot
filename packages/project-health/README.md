# @web-factor/project-health

Standalone Project Health & Quality Platform for WEB FACTOR repository:
- Code Metrics Engine (files, exports, interfaces, types, classes, functions, avg module size)
- Quality Analyzer (naming consistency, export completeness, duplications, orphan modules)
- Health Report Generator (Health Score 0-100, warnings, recommendations, Markdown/JSON export)
- CLI Foundation (`project-health analyze`, `metrics`, `report`)
