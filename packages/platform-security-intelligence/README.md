# @web-factor/platform-security-intelligence

Platform Security & Architectural Risk Intelligence for WEB FACTOR repository:
- Security Model (SecurityFinding, SecurityPolicy, SecuritySeverity, SecurityCategory, SecurityRisk, SecurityAssessment, SecurityReport)
- Security Analyzer (Policy compliance, exposure of public interfaces, risk classification)
- Security Validator (Policy enforcement, missing safeguards, security configuration validation)
- Security Report Generator (Platform Security Score 0-100, Markdown & JSON reports)
- CLI Foundation (`platform-security analyze`, `validate`, `report`)
