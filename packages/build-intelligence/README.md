# @web-factor/build-intelligence

Build & Compilation Configuration Intelligence Platform for WEB FACTOR repository:
- Build Model (BuildArtifact, BuildConfiguration, BuildIssue, BuildSeverity, BuildAssessment, BuildMetric)
- Build Analyzer (TypeScript tsconfig analysis, path mapping, package.json scripts & types completeness)
- Build Validator (Build config compliance, missing elements, severity classification)
- Build Report Generator (Build Health Score 0-100, Markdown & JSON reports)
- CLI Foundation (`build-intelligence analyze`, `validate`, `report`)
