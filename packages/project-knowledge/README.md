# @web-factor/project-knowledge

Monorepo Project Knowledge Graph Platform for WEB FACTOR ecosystem:
- Knowledge Model (KnowledgeNode, KnowledgeEdge, KnowledgeGraph, NodeCategory, EdgeType)
- Graph Builder (Builds knowledge graph connecting packages, modules, exports, interfaces)
- Query Engine (Find dependencies, find references, shortest path between modules, orphan node detection)
- Knowledge Report Generator (Graph statistics, most dependent modules, Markdown & JSON reports)
- CLI Foundation (`project-knowledge build`, `query`, `report`)
