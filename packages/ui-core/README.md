# @web-factor/ui-core

Independent UI Component Library for WEB FACTOR developer tools and platform apps.
Integrated with @web-factor/design-tokens.

Components:
- Foundation: Button, IconButton, Input, Textarea, Select, Checkbox, Switch, Badge, Spinner, Divider
- Layout: Stack, Inline, Box, Container, Grid, Flex
- Feedback: Alert, EmptyState, LoadingState, ProgressBar, Tooltip
