# @web-factor/monorepo-governance

Monorepo Governance & Package Policy Platform for WEB FACTOR repository:
- Package Policy Engine (PackagePolicy, PackageCategory, NamingPolicy, VersionPolicy)
- Workspace Validator (Scope compliance @web-factor/*, package.json checks, version alignment)
- Governance Analyzer (Policy compliance, deviations, missing metadata, export consistency)
- Governance Report Generator (Governance Score 0-100, Markdown & JSON reports)
- CLI Foundation (`monorepo-governance validate`, `policies`, `report`)
