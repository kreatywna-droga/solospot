# @web-factor/runtime-benchmark-datasets

Reference Benchmark Dataset & Performance Scenarios Library for WEB FACTOR Runtime Engine.

## Contents
- **`datasets/`**: Reference store datasets from 10 to 1,000 sections (`SMALL_STORE`, `MEDIUM_STORE`, `LARGE_STORE`, `XL_STORE`, `XXL_STORE`).
- **`scenarios/`**: Standard execution scenarios (`Full Render`, `Partial Render`, `Section Render`, `Preview Render`, `Export Render`, `Cache Hit`, `Cache Miss`).
- **`contracts/`**: Type contracts for benchmark suites and expectations.
- **`targets/`**: Reference latency, memory, and hit-ratio thresholds.
