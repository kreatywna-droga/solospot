# @web-factor/test-intelligence

Static Test Quality & Coverage Intelligence Platform for WEB FACTOR repository:
- Test Model (TestArtifact, TestSuite, TestCoverage, TestIssue, TestSeverity, TestAssessment)
- Test Analyzer (Source ↔ test file mapping, missing test detection, stub/empty test detection)
- Test Validator (Test policy compliance, severity classification, issue aggregation)
- Test Report Generator (Test Quality Score 0-100, Markdown & JSON reports)
- CLI Foundation (`test-intelligence analyze`, `validate`, `report`)
