# @web-factor/developer-experience-intelligence

Developer Experience (DX) & Ergonomics Intelligence Platform for WEB FACTOR repository:
- DX Model (Metrics, DXIssue, DXCategory, DXSeverity, DXAssessment, DXRecommendation, DXReport)
- DX Analyzer (Public API consistency, package structure ergonomics, export completeness, naming conventions)
- DX Validator (Policy compliance, Public API completeness, export documentation quality)
- DX Report Generator (Developer Experience Score 0-100, Markdown & JSON reports)
- CLI Foundation (`developer-experience analyze`, `validate`, `report`)
