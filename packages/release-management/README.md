# @web-factor/release-management

Release Readiness & SemVer Analysis Platform for WEB FACTOR repository:
- Version Analyzer (SemVer validation, package version alignment, bump recommendations)
- Release Validator (Metadata completeness, release readiness, CHANGELOG compliance)
- Changelog Analyzer (Parse CHANGELOG entries into Added, Changed, Fixed, Removed)
- Release Report Generator (Release Readiness Score 0-100, Markdown & JSON reports)
- CLI Foundation (`release-management validate`, `versions`, `report`)
