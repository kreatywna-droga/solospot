# @web-factor/architecture-validator

Monorepo Architecture Validation Platform for WEB FACTOR ecosystem:
- Architecture Rules (declarative rule definitions, categories, severities)
- Dependency Validator (forbidden imports, allowed layers, cycle detection)
- Structure Validator (required directory layout, mandatory files, naming conventions)
- Architecture Report Generator (Architecture Score 0-100, Markdown & JSON reports)
- CLI Foundation (`architecture-validator validate`, `rules`, `report`)
