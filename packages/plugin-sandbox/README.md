# @web-factor/plugin-sandbox

Plugin Security & Sandbox Contracts for WEB FACTOR ecosystem:
- Permission Model (Permission, PermissionGroup, PermissionScope, PermissionPolicy, PermissionRequest, PermissionGrant)
- Sandbox Contracts (SandboxContext, SandboxEnvironment, SandboxLimits, SandboxCapabilities, SandboxResult)
- Permission Validator (Validation, group conflicts, unknown capabilities detection)
- Security Report Generator (Risk levels, conflict analysis, Markdown & JSON reports)
- CLI Foundation (`plugin-sandbox validate`, `permissions`, `report`)
