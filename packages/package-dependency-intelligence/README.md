# @web-factor/package-dependency-intelligence

Package Dependency Architecture & Coupling Intelligence Platform for WEB FACTOR repository:
- Dependency Model (PackageNode, PackageDependency, DependencyGraph, DependencyCycle, DependencyIssue, DependencyAssessment)
- Dependency Analyzer (Dependency graph, cycle detection, orphan detection, high coupling detection)
- Dependency Validator (Policy compliance, coupling thresholds, graph consistency validation)
- Dependency Report Generator (Dependency Health Score 0-100, Markdown & JSON reports)
- CLI Foundation (`package-dependency analyze`, `validate`, `report`)
